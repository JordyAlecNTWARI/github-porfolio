Reservation-app
Stage Gauss&Co 2026

Application de réservation de créneaux pensée pour la cohérence des données et la résilience. La réponse à l'utilisateur est instantanée : la génération du PDF de confirmation et l'envoi de l'email se font en arrière-plan via une file de messages.

Node.js / Express TypeScript PostgreSQL / Prisma Redis RabbitMQ React Vitest
  • Unicité des réservations garantie même en requêtes simultanées (contrainte PostgreSQL)
  • Réponse 201 immédiate, découplée du worker (PDF et email en arrière-plan)
  • Cache Redis (30 s) avec invalidation automatique après réservation
  • Rate limiting fail-open + file de retry et dead letter pour les échecs
  • 6 fichiers de tests d'intégration sur la vraie stack (API + base + Redis)

Stage Gauss&Co 2026

Application de gestion de tâches en kanban (Todo / Doing / Done) avec mise à jour en temps réel : quand un utilisateur crée, déplace ou supprime une tâche, les autres la voient changer en direct, sans recharger la page. Monorepo API Node/Express + client React.

Node.js / Express TypeScript React Socket.IO JWT bcrypt
